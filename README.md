## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-21）加到八十五个，新做六个：

- **农历与节日**：填一个公历日期，出农历几月几、干支年与生肖，并列出接下来三个传统节日的倒数。农历用 1900–2099 年内置表换算，闰月单独标；除夕按腊月最后一天认（2027 年腊月是小月，除夕就是廿九）。
- **权限换算**：填 755 这种八进制数字，或者勾九个格子，实时看到 `-rwxr-xr-x` 和逐位含义；四位数字认得出设用户位 / 设组位 / 粘滞位，文件与目录两套解释分开给，常用权限一点就套上。
- **Markdown 目录**：粘一段 Markdown，按标题层级出带锚点的目录，代码块里的 `#` 不算标题。锚点按常见写法生成（小写、空格换连字符、中文保留、重名加 -1），能出 Markdown 列表或嵌套 HTML，序号按层各自重排。
- **油耗计算**：加了多少钱多少升、跑了多少公里，算百公里油耗、每公里油钱、每升能跑多远，再折算 500 公里与一年 1.5 万公里的花销，并给一个「这个水平算省还是费」的判断。
- **睡眠时间**：按 90 分钟一个周期算两个方向 —— 现在睡，几点起最轻；想几点起，几点该上床。中间留了可调的入睡时间，4 / 5 / 6 个周期一起列出来。
- **AA 分账**：总价、人数、服务费、优惠一填，出每人应付；支持按份数分（有人吃两份），抹零可选到元 / 角 / 分，并标出抹零后多收或少收多少。

## 功能

- 农历与节日：1900–2099 农历表换算，出干支生肖，列出接下来三个传统节日倒数
- 权限换算：755 这类数字与 rwxr-xr-x 互转，含设用户位 / 设组位 / 粘滞位
- Markdown 目录：按标题层级出锚点目录，代码块里的 # 不算，可出 Markdown 或 HTML
- 油耗计算：加多少升跑多少公里，出百公里油耗、每公里油钱与年度估算
- 睡眠时间：按 90 分钟周期算几点起或几点睡，含可调入睡时间
- AA 分账：总价 + 人数 + 服务费算出每人多少，可按份数分、抹零后差几毛标出来
- 全部在浏览器里算：图片、文本、JSON 都不上传，页面里没有任何后端接口
