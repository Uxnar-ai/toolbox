## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-15）加到五十五个，新做四个：

- **CSS 渐变**：色标用滑块定位置，最多八个；线性 / 径向切换，角度 0–360。右边实时是效果，下面一行 `background: linear-gradient(...)` 直接复制走。导出 1200×630 的图给封面用，画布算法跟 CSS 一致（0deg 从下往上、90deg 从左往右）。
- **图片裁剪**：拖图进来在画布上拉框，1:1 / 4:3 / 16:9 / 3:4 / 宽幅 可按比例锁；选区按原图像素算，导出 PNG / JPEG / WebP，能设输出上限（512 / 1024 / 2048）。遮罩 + 三分线 + 角点，默认先框好中间 70%，打开就知道怎么用。
- **JSON 对比**：两份接口返回粘进左右两栏，自动比对（不用点按钮）。按 `$.data.items[0].stock` 这种路径列出新增 / 删除 / 修改，可以只看不同，也能把差异清单复制走。数组按位置逐个比，不做「智能配对」——顺序变了会整片显示不同，这是故意的。
- **SVG 瘦身**：设计工具导出的 SVG 常带注释、metadata、inkscape / sodipodi 属性和一长串小数。勾选要清的东西，坐标小数位可选 0–2 位，右边马上预览；同一份示例从 1.04 KB 压到 430 B。文字节点一律不动，`<text>` 里的空格保留。

## 功能

- CSS 渐变：色标滑块定位置、最多八色，线性 / 径向与 0–360 角度，实时预览并一键复制 background，另可导出 1200×630 封面图
- 图片裁剪：画布上拉框、六种比例锁定，选区按原图像素导出 PNG / JPEG / WebP，输出尺寸可限制在 512 / 1024 / 2048 以内
- JSON 对比：两栏自动比对，按 $.a.b[0] 这种路径列出新增 / 删除 / 修改，支持只看不同与复制差异清单
- SVG 瘦身：去注释、metadata、编辑器属性与多余空白，坐标小数位 0–2 位可调，实时预览并给出压缩前后体积
- 全部在浏览器里算：图片、文本、JSON 都不上传，页面里没有任何后端接口

## 技术栈

HTML · CSS · 原生 JS（构建脚本 Python 3）
