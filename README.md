# 工具台 toolbox · 二十个打开就能用的小工具

> 二十个打开就能用的小工具合在一个静态站里：JSON 排版、文本整理、时间戳、正则解剖台、文本对比、编码解码、哈希校验、Cron 表达式、日期计算、命名风格、随机生成、金额大写、单位换算、颜色工具箱、二维码、图片压缩、CSV 转表格、中英混排加空格、字数统计、网址拆解。零后端、零端口。

[English](README.en.md) | 中文

## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮把工具箱从八个补到十二个，加的都是「手边真会用」的：

- **文本对比**：改前改后各粘一遍。先用最长公共子序列对齐整行，再把成对的删/加行做字级比对，只把真正变了的字标出来；长段相同的行折叠成一行提示，差异可以按 `+`/`-` 的形式复制走。
- **二维码生成**：自带编码库（MIT），中文按 UTF-8 进码而不是让浏览器按 Latin-1 编，容错 L/M/Q/H 四档，静区固定四个点，下载的 PNG 按整数倍放大，扫得动。
- **编码解码**：Base64（含网址安全字符 -_）、网址转义、HTML 转义、Unicode 转义、拆 JWT —— JWT 会顺手把签发/过期时间换算成本地时间并算出还剩多久，但不验签，页面上写清楚。
- **哈希校验**：文件拖进来出 MD5 / SHA-1 / SHA-256 / SHA-512。SHA 系列走浏览器自带的 crypto.subtle，MD5 浏览器没有，页面里自己实现（已用空串、abc、1000 个 a、中文串四组向量对过）。把官网给的校验值粘进比对框，按长度自动认出是哪种算法并判定对不对。

顺带修了两个一直存在的小毛病：构建时 favicon 的模板引用从来没被替换过（每个工具页的标签图标都是 404），以及首页按分组渲染时，新加的工具会因为追加在表尾而重新起一个同名分组头。现在按 `GROUP_ORDER` 排序渲染，图标也统一从 `assets/icon.svg` 取。

第三次补货（十二 → 十五），全是写服务端时天天碰到的那点事：

- **Cron 表达式**：一条 crontab 进，中文说明 + 接下来 10 次确切时间出。五段支持 `*` / `a-b` / `*/n` / `a/n` / `1,15` 任意组合，月份星期认英文缩写与 `7=周日`，`@daily` 这类别名也认。求下一次不用分钟级暴力循环——按天匹配后再扫当天的时和分，闰年、月末这些边界都是毫秒级。日和星期同时限定时的语义按 crontab 的老规矩走：满足其一即跑。
- **命名风格转换**：一行一个字段名，同时出 camelCase / PascalCase / snake_case / CONSTANT_CASE / kebab-case / dot.case / 空格 / Title Case 八种。拆词除了分隔符还认驼峰边界与连续大写缩写（`HTTPServer` 拆成 http + server，而不是 h-t-t-p），多行一次转完，结果整列可复制。
- **日期计算**：两个日子差多少天、多少个工作日、按年月日怎么读；反过来从某天往后推 N 天 / N 个工作日 / N 个月是几号。月份推进按日号夹取（1 月 31 日 + 1 个月 = 2 月 28 日），全程用 UTC 算，绕开夏令时那天差一天的老坑。

- **随机生成**：密码、UUID v4、十六进制、纯数字，一次出一批。随机取自浏览器自带的安全随机源，用拒绝采样而不是直接取模（取模会让靠前的字符出现得更频繁）。密码可以避开 `0 O o 1 l I`，旁边按 长度 × log2(字符池) 估出多少位随机数并给出「够不够用」的判断。

第四次补货（十六 → 二十），这一轮都在「文本进出」这件事上：

- **CSV 转表格**：逗号 / 制表符 / 分号 / 竖线四种分隔符按行内出现次数自动认；引号里的逗号、换行、双写引号都按 RFC 4180 认。出来先是一张能看的表（表头固定、斑马纹、数字右对齐、点表头排序），再按同一份数据导出 Markdown / JSON / SQL INSERT / HTML / TSV。表格视图下点复制拿到的是 TSV，粘进 Excel 或飞书表格能直接分列。
- **中英混排加空格**：中文和英文、数字交界处补一个空格，中文之间多余的空格去掉，可选的还有全角字母数字转半角、英文标点后补空格。插入位置先用占位符标记再统一换成空格，所以不会出现「替换完又被下一条规则吃掉」的连锁反应；一个按钮能把结果里中英之间的空格全标出来，一眼看清改了哪儿。
- **字数统计**：中文字数、英文词数、数字串、字符（含/不含空格）、行数、段落、标点、最长一句，加上按 300 字/分 + 200 词/分折出来的阅读时长；右侧还列了微博、小红书、公众号摘要、短信、X 的字数上限，超了直接变红。高频字按字统计并过滤掉「的了是在」这类虚词。
- **网址拆解**：协议、域名、端口、路径、锚点逐段摊开，查询参数做成可编辑的表格——改值、删行，底下那条干净链接实时跟着变。一键去掉 utm_* / spm / gclid / from / scene 这些跟踪参数；参数表能整份复制成 JSON，重复的键自动并成数组。没写协议的链接按 https 处理。

顺手给首页加了即时搜索：二十个工具滚着找太慢，输入「表格」「颜色」就只剩匹配的卡片，空分组标题跟着隐藏，按 `/` 聚焦、Esc 清空。

## 功能

- 二十个工具同在一个静态站，零后端零端口
- 构建脚本从各工具模板生成，改动只在一处
- 文本对比：逐行对齐、行内字级高亮、相同段落折叠、差异可复制
- 二维码：中文 UTF-8、容错 L/M/Q/H、尺寸可调、下载 PNG、固定四个点静区
- 编码解码：Base64（网址安全字符）、网址、HTML、Unicode 转义、拆 JWT 并换算过期时间
- 哈希校验：MD5/SHA-1/SHA-256/SHA-512，粘贴校验值自动认算法比对
- 公共主题 12 个变量，日夜三态（跟随系统 / 浅 / 深），全站统一图标
- 窄屏单列，390px 下无横向溢出
- Cron 表达式：中文说明 + 下次 10 次、五段全语法、别名、报错精确到段
- 命名风格：八种写法一次出、缩写拆词、多行批量、整列可复制
- 日期计算：相差天数/工作日、年月日拆读、按天/工作日/月/年推进
- 随机生成：密码/UUID/十六进制/数字，安全随机源 + 强度估算
- CSV 转表格：自动认分隔符、引号内逗号、表头排序、六种导出格式
- 中英混排：中英/中数之间补空格、全角转半角、改动可标出
- 字数统计：中文字/英文词/段落/阅读时长 + 五个平台字数上限
- 网址拆解：参数改删实时重组、一键去跟踪参数、参数表转 JSON
- 首页即时搜索，二十个工具按关键词过滤

HTML · CSS · 原生 JS（构建脚本 Python 3）
