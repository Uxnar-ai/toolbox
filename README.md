## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-17）加到六十四个，新做四个：

- **字符查询**：按码点逐字拆开，每个字符给出码点（含十进制）、UTF-8 字节、JS 的 \\uXXXX 转义与 HTML 实体，并按 Unicode 区间标出「汉字 / 全角符号 / 中文标点 / 零宽 / BOM / emoji」。看不见的字符不画豆腐块，换成 SP / NBSP / 全角 / ZWSP / ZWJ / BOM 文字徽标。反查支持 `4F60`、`U+4F60`、`20320`、`&#x4F60;` 四种写法，直接贴一个字也认。
- **图片尺寸换算**：两块互为反向 —— 像素配分辨率算打印厘米，打印厘米配分辨率算需要多少像素；锁比例时改宽自动算高。附十种常见尺寸（A4 印刷 / A4 家用 / A3 海报 / 一寸 / 二寸 / 六寸 / 公众号首图 / 方图 / 手机壁纸 / 1080p），点一行直接套用并切到它建议的分辨率，并说清这一档打出来清不清楚。
- **Git 急救**：36 个「做错了怎么退回去」的场景，分六组：提交改错了、分支与暂存、文件还原、推送出事、查问题、一次配置。每条给一句「什么时候用」、一段可直接复制的命令、以及「什么时候别这么干」（比如 amend 已经推过的提交、`git clean -fd` 会删掉从没提交过的文件）。
- **常用正则**：33 条按六类整理，每条都带「该匹配」和「不该匹配」的样例，页面打开时当场跑一遍并标 ✓ / ✗ —— 规则写错一眼看得出来。右侧试跑框可以粘自己的文字，按行高亮命中处，并统计有多少行完全符合。

## 功能

- 字符查询：逐码点给码点值、UTF-8 字节、JS 转义与 HTML 实体，看不见的字符换成文字徽标；填码点也能反查是哪个字
- 图片尺寸换算：像素与打印厘米互算，锁比例改宽自动算高，十种常见尺寸一键套用
- Git 急救：36 个「做错了怎么退回去」的场景，给命令也标着什么时候别这么干，可搜索、可分类
- 常用正则：33 条带自测样例，打开就当场跑一遍标 ✓ / ✗，试跑框按行高亮命中处
- 全部在浏览器里算：图片、文本、JSON 都不上传，页面里没有任何后端接口

## 技术栈

HTML · CSS · 原生 JS（构建脚本 Python 3）

## 运行

```bash
python scripts/build_toolbox.py
# 然后把 src/toolbox/ 丢给任意静态服务器
```
