## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-16）加到六十个，新做五个：

- **字幕时间轴**：字幕整体早了晚了，填个秒数一键挪正，负数是提前、挪到 0 之前就停在 0。SRT 与 VTT 双向转换，文字、条数、换行原样保留；带 `align:` 这类定位信息的 VTT 转 SRT 会丢掉那半截，页面里写了。统计条给条数、字幕总时长、首末时间。
- **图片加水印**：拖图进来打一行字，九宫格定位、字号按图宽的百分比（1–20%）、透明度与颜色随调；勾上「满图平铺」就铺满整张防截取。导出的还是原分辨率，图片不出本机。
- **照片信息**：自己解析 JPEG 的 APP1，把拍摄时间、机型、镜头、光圈曝光、GPS 坐标读出来分组列出，敏感项标红。要发出去就点「清除全部信息并导出」——靠 canvas 重绘，EXIF 段自然没了，顺带报出比原图小多少。
- **条码生成**：Code128（Code Set B，带校验位）与商品条码 EAN-13（12 位自动补校验位，13 位校验错会指出正确值）。渲染成 SVG，白底、10 模块静区、连续黑条合并成单个 rect；PNG 走 3 倍分辨率重绘。
- **长文分块**：一段长文分几条发出去，定个字数上限就按空行分段、按句号问号断开，实在没标点才硬切。「均分成 N 段」不是简单除一下，而是从 20 字起逐步放宽上限，取块数最接近目标的那一档。

## 功能

- 字幕时间轴：整段字幕按秒数平移（负数提前、不越过 0），SRT 与 VTT 互转，文字与顺序不动，附条数与总时长
- 图片加水印：九宫格定位、字号按图宽百分比、透明度与颜色可调，满图平铺防截取，导出保持原分辨率
- 照片信息：解析 JPEG 的拍摄时间、机型、镜头、光圈曝光与 GPS 坐标，敏感项标红，一键清除后重新导出
- 条码生成：Code128 与 EAN-13（自动补 / 校验校验位），SVG 带 10 模块静区、黑条合并，另可导出 3 倍 PNG
- 长文分块：按字数或按段数切分，在段落与句号处断开，逐块复制或一键导出 txt
- 全部在浏览器里算：图片、文本、JSON 都不上传，页面里没有任何后端接口

## 技术栈
