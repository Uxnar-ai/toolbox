表格转 SQL

从 Excel 或接口复一份表进来，直接出建表语句和插入语句，表名列名类型都替你想好。

表格数据0 行
表名 首行当表头
SQLMySQL
点「生成 SQL」
支持 CSV / TSV（逗号、制表符、分号自动认）和 JSON 数组

首行是表头，空单元格写成 NULL。类型按整列的值推：全是整数 → 整数，全是小数 → 两位小数，true/false → 布尔，2026-11-21 09:12 这种 → 时间，其余按最长值给文本长度。
中文表头直接用，会用引号包起来（MySQL 反引号、PostgreSQL 双引号）。表名建议用英文小写，很多库对中文表名不友好。
JSON 数组也吃：[{"a":1,"b":"x"}] 粘进来会按出现过的键合并成列。

数据只在你的浏览器里，不上传、不记录。
