## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-22）加到八十九个，新做四个：

- **SVG 转 PNG**：粘一段 SVG，右边立刻出图。宽度留空按原尺寸、填了就等比缩放，再叠一层 2/3/4 倍率给高清图；底色可透明、白、黑或自定色。导出直接是 PNG，还能「复制为图片」贴进聊天窗口。
- **看 ZIP 里有什么**：拖个 zip 进来先读文件目录，不解压就列出名字、原始大小和压缩率，想拿哪个点哪个单独取出。文件名按 UTF-8 试、失败回退 GBK；docx / jar / apk 本质上也是 zip，一样能看。
- **离假期还有几天**：下一个假期是哪天、还剩多少天，未来八个假期一起排。春节按除夕起算，春节 / 端午 / 中秋用 1900–2099 农历表推，清明按节气公式算，另外给一条今年过完几成的进度条。
- **XML 整理与转换**：粘一段 XML 自动排好版、或压成一行，也能转 JSON（属性加 `@`、文字放 `#text`、同名兄弟自动成数组）。三种视图随时切，写错了直接指到第几行第几列。

## 功能

- SVG 转 PNG：粘代码出图，宽度 / 倍率 / 底色自定，可下载或复制成图片
- 看 ZIP 里有什么：不解压先列清单，按需单个取出，中文名 UTF-8 / GBK 都认
- 离假期还有几天：下一个假期倒计时 + 未来八个，农历节日与清明节气自己算
- XML 整理与转换：排版 / 压成一行 / 转 JSON，报错定位到行列
- 全部在浏览器里算：图片、压缩包、文本、JSON 都不上传，页面里没有任何后端接口
