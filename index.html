工具台 toolbox

一堆打开就能用的小工具。全在浏览器里算，不上传服务器，关掉页面什么都不留。

文本与数据
{}↗

JSON 排版

粘进去就排好：缩进、压缩、查错定位到行列、键排序，全在浏览器里算。

排错定位键排序压缩
≡↗

文本整理

一堆行粘进去：去重、排序、去空行，再变成逗号串 / JSON 数组 / Markdown / SQL IN。

去重去空行格式转换
.*↗

正则解剖台

一条正则拆成语法树、编译成 NFA 画出来，三种引擎跑同一输入串对比步数与耗时。

语法树NFA / DFA三引擎
±↗

文本对比

改前改后各粘一遍，哪行删了、哪行加了、哪几个字变了，一眼看出来。

逐行对比字级高亮可折叠
⇄↗

编码解码

Base64、网址转义、HTML 转义、\u 转义、拆 JWT，粘进去选一下就好，中文不乱码。

Base64JWT中文安全
#↗

哈希校验

文件拖进来出 MD5 / SHA-256 指纹，官方给的校验值粘进去立刻告诉你对不对。

不上传四种算法自动比对
aA↗

命名风格转换

一行一个字段名，粘进来同时出八种写法：驼峰、下划线、连字符、常量，点一下复制。

八种写法批量一键复制
⊞↗

CSV 转表格

一段逗号或制表符分隔的数据粘进来就成表，点表头能排序，再导出 Markdown、SQL、JSON。

自动识别分隔符表头排序六种导出
␣↗

中英混排加空格

中文里夹英文和数字的地方自动补一个空格，读起来不挤；全角字母数字也能转半角。

中英空格全角转半角标出改动
字↗

字数统计

边写边算：中文字数、英文词数、行数段落、大概读多久，顺带看各平台字数上限还剩多少。

实时统计阅读时长平台上限
⛓↗

网址拆解

贴一条链接，域名、路径、每个参数逐段拆开；跟踪参数一键去掉，复制一条干净的。

参数拆解去跟踪可编辑
时间与任务
⏱↗

时间戳

日志里的时间戳一行一个粘进来，变成本地时间、UTC 和相对时间；反过来也能转。

秒 / 毫秒批量双向
⏰↗

Cron 表达式

粘一条 crontab 进来：先用中文说清它什么时候跑，再列出接下来 10 次的确切时间。

看人话下次 10 次五段

日期计算

两个日子差多少天、多少个工作日；从某天往后推 N 天是几号，也能算。

相差天数工作日往后推

金额大写

票据规范日期大写

单位换算

一个数换出同一类量的全部单位，带市尺、斤两、亩，点一行就复制。

市制批量一键复制

颜色工具箱

色值四种写法互转、9 档色阶、搭配色与对比度；拖张截图进来能点取色。

取色色阶对比度

本地压缩不上传质量可调

二维码生成

中文下载 PNG容错可调
