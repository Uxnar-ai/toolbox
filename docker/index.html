Docker 命令速查

想干的事写一句，找到对应命令，点一下就复制走 —— 不用再翻文档。

—
小心这两条：docker system prune -a 会删掉所有没在用的镜像， 下次用到要重新拉；docker compose down -v 连数据卷一起删，库里的数据就没了。 不确定的时候先跑对应的 df / ls 看一眼。

起名省事：给容器起个名字（--name web），后面所有命令都能用名字代替一长串 ID。
看文档不用开浏览器：docker run --help、docker compose up --help 里的参数表比网页快也比网页准。
退出码很关键：容器反复重启，先看 ExitCode —— 137 是被强杀（多半内存不够或 OOM），1 是程序自己报错退出，0 是正常跑完了。

命令都是常用写法，示例里的容器名统一叫 web，换成自己的即可。
