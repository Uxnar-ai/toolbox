## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-25）加到一百零三个，新增城市天气、表格转 SQL、跨时区开会，首屏多了「生活查询」分组：

- **城市天气**：输城市名或 9 位城市代码，出当前温度、体感、湿度、风力风向、气压、日出日落和 PM2.5 / PM10；下面七天预报每天一行，带温度区间条。2500 多条城市代码表整个内嵌，输入即联想，查过的城市留在本机（最多 8 个），下次打开回到上次那个。天气数据浏览器直连公开接口，没有中转。
- **表格转 SQL**：从 Excel 或接口复一张表粘进去，直接出建表语句和批量 INSERT。类型按整列的值推 —— 整数、两位小数、布尔、日期时间各有对应写法；CSV（逗号 / 制表符 / 分号自动认）和 JSON 数组都吃，MySQL / PostgreSQL / SQLite 三种方言的引号与布尔字面量分别处理。
- **跨时区开会**：挑两三个城市，24 格一行铺开，深色格子就是那个城市在上班（9–18 点）。全都在上班的时段直接写成「16:00–18:00（共 2 小时）」；凑不出交集时给出最接近的一小时，并列出各地当时几点。夏令时按浏览器时区库算，不用自己加。


## 功能

- 城市天气：温度、体感、湿度、风力、气压、日出日落 + 七天预报，2500 多条城市代码内嵌
- 表格转 SQL：CSV / JSON 粘进来出建表与批量 INSERT，类型自动推断，三种方言
- 跨时区开会：24 格铺开看谁在上班，交集时段直接写成区间，夏令时自动
- 查过的城市留在本机（最多 8 个），一点就开，下次默认回到上次那个
- 天气数据浏览器直连公开接口，没有中转服务器
- 全部在浏览器里算：图片、压缩包、文本、JSON 都不上传，页面里没有任何后端接口
