cubic-bezier(x1, y1, x2, y2)：起点固定在左下 (0,0)，终点固定在右上 (1,1)，中间两个点决定快慢。 两个 x 只管「什么时候发生」，两个 y 管「已经走了多远」—— y 越靠上，前半段冲得越快。
记住三种手感：慢起（0.42, 0, 1, 1）像推重物起步；快起慢停（0, 0, 0.58, 1）像手指甩出去； 两头缓（0.42, 0, 0.58, 1）最稳，适合弹窗和页面切换。

纯前端，无请求。数值范围 0–1，超出会显示成边界。
