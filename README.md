## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-18）加到六十八个，新做四个：

- **IPv6 地址**：粘一个地址或网段（`2408:8207::1/64`、`fe80::1`、`::ffff:198.51.100.10`、带网卡名的 `ff02::1%eth0` 都认），给出最短写法与完整写法、网络地址与首末可用地址、能放多少台（2 的几次方），并按常见地址段判出它属于公网单播 / 链路本地 / 唯一本地 / 组播 / 文档示例 / NAT64。另外两块反向：填一个地址判断在不在本段里；填 MAC 生成对应的 `fe80::` 局域网地址（EUI-64，U/L 位翻转）。
- **菜谱份量换算**：整段菜谱粘进来，填原份数和要做的份数，克数、毫升、勺数、个数按比例重算；`100-150 g` 这种区间两头一起缩，`1/2 杯` 这种分数也认；180 度、25 分钟、第 3 步这些跟份数无关的数字不动。改了哪几个数会在结果里标出来，另附一张「一汤匙是多少克」的换算表（面粉 / 白砂糖 / 盐 / 大米 / 食用油）。
- **两步验证码**：粘网站给的 Base32 备份密钥或整条 `otpauth://` 链接，直接算当前验证码；6 / 8 位、30 / 60 秒、SHA-1 / SHA-256 / SHA-512 都能选，带倒计时进度和下一组预览。计算走浏览器的 WebCrypto，密钥不写本地存储、不发任何网络请求。
- **代码美化**：从网页或构建产物里扒出来挤成一行的 HTML、CSS、JS，粘进来按缩进排好；HTML 与 CSS 也能反向压成一行。只动空白不动内容 —— JS 的字符串、模板串、正则和注释原样保留，换行只加在 `;` `{` `}` 之后（`for(;;)` 里的分号除外），不碰自动补分号；JS 压缩故意不做，压错一处页面就白屏。

## 功能

- IPv6 地址：最短 / 完整写法、网络与首末可用地址、地址数量，判出公网单播 / 链路本地 / 组播，MAC 一键生成 fe80:: 地址
- 菜谱份量换算：整段菜谱按份数缩放，克数勺数比例重算，区间与分数都认，炉温与分钟不动
- 两步验证码：Base32 密钥或 otpauth 链接直接出码，6 / 8 位与三种算法，带倒计时，WebCrypto 本地算
- 代码美化：HTML / CSS / JS 排版，HTML 与 CSS 也能压成一行，只动空白不动内容
- 全部在浏览器里算：图片、文本、JSON 都不上传，页面里没有任何后端接口

## 技术栈

HTML · CSS · 原生 JS（构建脚本 Python 3）

## 运行

```bash
python scripts/build_toolbox.py
# 然后把 src/toolbox/ 丢给任意静态服务器
```
