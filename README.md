## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮把工具箱从八个补到十二个，加的都是「手边真会用」的：

- **文本对比**：改前改后各粘一遍。先用最长公共子序列对齐整行，再把成对的删/加行做字级比对，只把真正变了的字标出来；长段相同的行折叠成一行提示，差异可以按 `+`/`-` 的形式复制走。
- **二维码生成**：自带编码库（MIT），中文按 UTF-8 进码而不是让浏览器按 Latin-1 编，容错 L/M/Q/H 四档，静区固定四个点，下载的 PNG 按整数倍放大，扫得动。
- **编码解码**：Base64（含网址安全字符 -_）、网址转义、HTML 转义、Unicode 转义、拆 JWT —— JWT 会顺手把签发/过期时间换算成本地时间并算出还剩多久，但不验签，页面上写清楚。
- **哈希校验**：文件拖进来出 MD5 / SHA-1 / SHA-256 / SHA-512。SHA 系列走浏览器自带的 crypto.subtle，MD5 浏览器没有，页面里自己实现（已用空串、abc、1000 个 a、中文串四组向量对过）。把官网给的校验值粘进比对框，按长度自动认出是哪种算法并判定对不对。

顺带修了两个一直存在的小毛病：构建时 favicon 的模板引用从来没被替换过（每个工具页的标签图标都是 404），以及首页按分组渲染时，新加的工具会因为追加在表尾而重新起一个同名分组头。现在按 `GROUP_ORDER` 排序渲染，图标也统一从 `assets/icon.svg` 取。

第三次补货（十二 → 十五），全是写服务端时天天碰到的那点事：

- **Cron 表达式**：一条 crontab 进，中文说明 + 接下来 10 次确切时间出。五段支持 `*` / `a-b` / `*/n` / `a/n` / `1,15` 任意组合，月份星期认英文缩写与 `7=周日`，`@daily` 这类别名也认。求下一次不用分钟级暴力循环——按天匹配后再扫当天的时和分，闰年、月末这些边界都是毫秒级。日和星期同时限定时的语义按 crontab 的老规矩走：满足其一即跑。
- **命名风格转换**：一行一个字段名，同时出 camelCase / PascalCase / snake_case / CONSTANT_CASE / kebab-case / dot.case / 空格 / Title Case 八种。拆词除了分隔符还认驼峰边界与连续大写缩写（`HTTPServer` 拆成 http + server，而不是 h-t-t-p），多行一次转完，结果整列可复制。
- **日期计算**：两个日子差多少天、多少个工作日、按年月日怎么读；反过来从某天往后推 N 天 / N 个工作日 / N 个月是几号。月份推进按日号夹取（1 月 31 日 + 1 个月 = 2 月 28 日），全程用 UTC 算，绕开夏令时那天差一天的老坑。

- **随机生成**：密码、UUID v4、十六进制、纯数字，一次出一批。随机取自浏览器自带的安全随机源，用拒绝采样而不是直接取模（取模会让靠前的字符出现得更频繁）。密码可以避开 `0 O o 1 l I`，旁边按 长度 × log2(字符池) 估出多少位随机数并给出「够不够用」的判断。

第四次补货（十六 → 二十），这一轮都在「文本进出」这件事上：

- **CSV 转表格**：逗号 / 制表符 / 分号 / 竖线四种分隔符按行内出现次数自动认；引号里的逗号、换行、双写引号都按 RFC 4180 认。出来先是一张能看的表（表头固定、斑马纹、数字右对齐、点表头排序），再按同一份数据导出 Markdown / JSON / SQL INSERT / HTML / TSV。表格视图下点复制拿到的是 TSV，粘进 Excel 或飞书表格能直接分列。
- **中英混排加空格**：中文和英文、数字交界处补一个空格，中文之间多余的空格去掉，可选的还有全角字母数字转半角、英文标点后补空格。插入位置先用占位符标记再统一换成空格，所以不会出现「替换完又被下一条规则吃掉」的连锁反应；一个按钮能把结果里中英之间的空格全标出来，一眼看清改了哪儿。
- **字数统计**：中文字数、英文词数、数字串、字符（含/不含空格）、行数、段落、标点、最长一句，加上按 300 字/分 + 200 词/分折出来的阅读时长；右侧还列了微博、小红书、公众号摘要、短信、X 的字数上限，超了直接变红。高频字按字统计并过滤掉「的了是在」这类虚词。
- **网址拆解**：协议、域名、端口、路径、锚点逐段摊开，查询参数做成可编辑的表格——改值、删行，底下那条干净链接实时跟着变。一键去掉 utm_* / spm / gclid / from / scene 这些跟踪参数；参数表能整份复制成 JSON，重复的键自动并成数组。没写协议的链接按 https 处理。

顺手给首页加了即时搜索：二十个工具滚着找太慢，输入「表格」「颜色」就只剩匹配的卡片，空分组标题跟着隐藏，按 `/` 聚焦、Esc 清空。

第五次补货（二十 → 二十四），这一轮是一组「换算与修复」的活：

- **网段计算**：一个 IP 带 `/26` 或带掩码进去，网络地址、广播地址、可用主机范围、可用台数、子网掩码、反掩码、地址类型（私有 / 回环 / 链路本地 / 文档示例段）一次列全。掩码写法会校验连续性（`255.0.255.0` 直接拒掉，而不是算出一个假结果），`/31` 按点对点算两个可用地址、`/32` 算单个地址，跟设备上的实际行为一致。往下还能按需要的子网数切分，列出每个子网的地址范围；再填一个 IP 就能判定它在不在这个段里，顺带说明它是不是网络地址或广播地址。
- **百分比计算**：四块并排，各自实时——打折（原价 + 几折，出到手价与省下的钱）、涨跌（原值 → 新值，出百分比与倍数）、占比（分子分母，出百分数与离 100% 还差多少）、增减（基数 + 百分比，负数就是减）。分母为 0 直接说明为什么不能算，而不是吐一个 Infinity。
- **乱码修复**：粘一段乱码进来，按「UTF-8 被当西文」「GBK 被当西文」「Big5 被当西文」「GBK 被当 UTF-8」各试一遍，结果按中文占比排序，最像原文的排第一并高亮，点一下就复制；网址编码、HTML 实体、反斜杠 u 转义也能一起还原。判断「修不修得回来」是有依据的：出现「锟斤拷」「ï¿½」这类替换符，说明原始字节在转换时已经被丢掉了，页面会直接说清楚，不假装能救。
- **Markdown 预览**：左边写右边出，标题、加粗斜体删除线、行内代码、代码块（内容按文本转义，不会被当成标签）、有序无序列表（含两层嵌套）、引用、表格（可以省略行首行尾竖线）、分割线、链接与图片。满意了复制 HTML、复制纯文本，或者直接下载一个带内联样式的独立网页。

第六次补货（二十四 → 二十七），这一轮三件都在图片和数字上：

- **图片转 WebP**：JPG / PNG / BMP / AVIF / SVG（写死宽高）一次拖进来，全在浏览器里用 canvas 编成 WebP，质量 50–100、最大长边可选，改参数自动重转。透明背景不填白，EXIF 方向按 `imageOrientation:'from-image'` 纠正，转换队列一张一张走，避免大图把内存吃爆。打开自带两张现画示例（照片 + 透明圆），能直接看出体积差。
- **进制转换**：一个输入框认 `0x` / `0b` / `0o` / `#` 前缀，BigInt 存值所以位数不限；十进制带千分位、二进制四位分组，每行可复制。下面一排位运算（与或异或左右移、无符号 32 位取反），结果同时给十进制、十六进制、二进制，码位落在能显示的区段时补一个对应字符。
- **图片转 Data URI**：小图变能贴进 HTML / CSS 的一长串，四种写法（完整 URI、纯 base64、CSS background、img 标签）可复制，并算出膨胀倍数、超过 30 KB 直接劝退；反过来粘 URI 或纯 base64 就能还原成图并下载，没写前缀时按魔数认 JPEG / GIF / WebP / PNG。

第七次补货（二十七 → 三十一），加了一件在「发东西出去」时天天用得上的事，另外三件补文本上的空白：

- **二维码识别**：截图、照片、屏幕截图拖进来（或直接 `Ctrl+V` 粘贴）就能读出里面的文字和链接，读到的网址当场给「打开」。解码走本地打包的 jsQR，图片不出浏览器；大图先缩到 1100 再解，解不出换 2000 重试，一张解不出不影响下一张。
- **文本脱敏**：手机号、邮箱、身份证、银行卡、IP、长串密钥六类规则，各自可开关；默认保留首尾（`138****5678`、`6222**********0123`、`203.0.113.*`），也能一键整段打码。规则按顺序占位，18 位身份证不会被卡号规则再遮一遍；结果区把遮掉的位置标出来，复制走的是纯文本。
- **正则查找替换**：查找框、替换框、四个开关，输入即算。替换进去的内容用绿色标出，删掉的内容不留在结果里（只在原位画一条竖线，悬停看原文）——这样在结果区框选复制不会把删掉的字带走。带五个常用预设，报错直说哪一段不对。
- **YAML 转 JSON**：两个方向都能转，缩进 2 或 4，写错定位到行列；「把结果换到左边」可以立刻往返验证，也能下载成 `config.json` / `config.yaml`。JSON 结果的键名上色，只认行首的键，不会把字符串里的冒号误认成结构。

首页顺手加了「最近用过」：点过的工具记在本地（最多八个），下次打开置顶一排胶囊。

顺手给 WebP 页加深了一处：第一张图按 60/75/85/95 四档各转一次，列出体积和相对原图省多少，点「用这档」直接把质量条套上——挑质量时不用来回拖滑块猜。

第八次补货（三十一 → 三十五），三件开发时顺手要用的，加一个写文档时的小工具：

- **SQL 排版**：挤成一行的 SQL 粘进来，按子句断行（SELECT / FROM / WHERE / GROUP BY / JOIN / ON …），SELECT 列表和 GROUP BY 一项一行；关键字统一大写，缩进 2 / 4 / 不缩进可选，也能反向压成一行并去掉注释。中间是个自己写的词法器：字符串（含 `''` 转义）、反引号、行注释、块注释、`::`、`->>` 先切出来保护住再重排。`BETWEEN 1 AND 5` 里的 AND 不会当成条件断行，`CREATE TABLE` 的括号按列清单一行一列，括号里是子查询就再进一层。
- **JSON 转类型**：贴一段接口返回，出 TypeScript interface / Go struct / Python dataclass。数组里的对象按字段取并集，只在部分元素里出现的字段自动标成可选（`?` / `,omitempty` / `Optional[...]`）；整数和小数分开推（Go 用 int64 / float64）；Go 字段名转大写补 `json` tag，带缩写表（ID / URL / API / JSON …）；Python 输出带 `from __future__ import annotations`，嵌套对象单独成类。JSON 写错直接报解析器给的行列。
- **号码校验**：身份证（15 / 17 / 18 位，17 位和 15 位自动补成 18 位）、银行卡 Luhn、统一社会信用代码、EAN-13 条码、ISBN-10，粘一个号码自动认类型。身份证会读出出生日期、年龄、性别、省级地区码，日期不存在也会说；校验位错了直接告诉你该是哪一位。
- **特殊符号**：箭头、对勾、数学、货币、圈号、单位、标点、勾选框、装饰、项目符号、希腊字母、表情十二组二百七十多个字符，点一下就复制，同时攒到底下的收集区。

这一轮没有一行服务器代码：四个页面加三份纯计算脚本（`sqlfmt.js` / `typegen.js` / `chk.js`），构建时一起打进 `assets/<工具>/`，主站仍是纯静态目录。

第九批（三十五 → 三十九），两件开发时要用的、一件写配置用的、一件算钱用的：

- **curl 转代码**：从开发者工具「Copy as cURL」出来的命令，粘进来就变成 fetch / Python requests / Go 标准库 / PowerShell 四种写法。中间是个自己写的分词器：单双引号、反斜杠与脱字符与反引号三种续行、`-sSL` 这种合起来的短参数、`-X / -H / -d / --json / -F / -u / -b` 都认；请求体按内容判成 JSON（直接内联成对象，键值对齐）、表单（URLSearchParams / dict）或原样文本，缺 Content-Type 会自动补。`-k -L -s -o` 这类只影响 curl 行为的参数不写进代码，但会提示要注意什么。
- **HTTP 状态码**：54 条，标准码之外还收了 nginx 自己记的 499 / 444 和 Cloudflare 的 52x。每条给中文解释、「最常见的原因」和「下一步看哪儿」，搜索同时匹配编号、英文名、中文说明和隐藏标签，搜「超时」「限流」「证书」「缓存」都能命中。
- **.gitignore 生成**：24 个技术栈分四组，勾完直接出内容。同一条规则在多块里出现只留一份，注释行保留分段标题，反向规则（感叹号开头）不参与去重 —— 漏了会让本该保留的文件被忽略。复制或下载。
- **贷款计算**：金额、年利率、年限进，月供、总利息、还款总额、每期明细出。等额本息逐期按剩余本金算利息、末期本金取余额消掉浮点尾差；等额本金每期本金固定、利息递减，两种方式能直接对比谁的利息少、谁的前期压力大。

第十批（三十九 → 四十三），两件做站要用的、一件造测试数据用的、一件对时间用的：

- **网站图标生成**：拖一张方形图进来，直接出 `.ico`（16 / 32 / 48 / 64 / 128 / 256 六档打包）和单张 PNG（180 与 512）。ICO 用 PNG 段而不是 BMP，体积小一个量级；非正方形按短边居中裁，不会被拉扁。打包是自己拼的：6 字节头 + 每张 16 字节目录（256 按规范写 0）+ 连续图片数据，偏移逐张累加。
- **HTML 转 Markdown**：从网页复制的内容直接粘进来（粘贴时优先取富文本那一份），右边出 Markdown。标题、加粗斜体、删除线、行内代码、带语言名的代码块、有序/无序多级列表、任务清单、链接、图片、引用、分隔线、表格都认；脚本和样式整棵子树丢掉，整页源码贴进来只取 body。
- **假数据生成**：勾要哪几列、填行数，一次出表格，能复制成 TSV 贴进表格软件、复制 JSON、导 CSV。十七类字段，身份证按加权因子加校验码表算对，银行卡按 Luhn 算对；邮箱统一 `@example.com`，不会撞到真人。
- **时区对照**：定一个时刻，看二十个城市各是几点、差几小时、跨不跨日、那边在不在上班时段。时差用 `Intl.DateTimeFormat` 现算而不是查表，夏令时自动跟着变；半小时时区（孟买 +5:30）按分钟算，不会四舍五入丢半小时。

第十一批（四十三 → 四十七），四件都是「写完文档、调完样式、看接口返回」时手边要用的：

- **隐藏字符体检**：把文字里看不见的字符逐字标出来 —— 普通空格是点、制表符是箭头、不间断空格（NBSP）和全角空格各是一种标记、零宽字符（ZWSP / ZWJ / BOM / RLM 等）直接写出名字。中文排版里从网页复制一段话常常混进 NBSP，代码里混进零宽字符又极难找，这一页扫一眼就知道。顺手能一键整理：去零宽与 BOM、NBSP 和全角空格换普通空格、换行统一 LF、去掉行尾空格。浏览器会把输入框里的 CRLF 统一成 LF，所以「查一个文件」走 FileReader 读原始字节，真能看出一个文件到底用哪种换行。
- **表格对齐**：Markdown 表格最烦的是手写时空格数对不齐，渲染出来还好、源码里一坨。这一页按「一个中文算两格」的真实显示宽度补空格，数字列自动靠右、文字列靠左；没有竖线只有 Tab 的数据（Excel、飞书表格复制出来的那种）直接按制表符切，转成表格；单元格里的竖线自动转义，不会把表格撑破。
- **阴影与圆角**：五个滑块（X / Y / 模糊 / 扩散 / 圆角）加颜色和透明度，卡片当场变；五个常用预设（轻投影、浮起、硬边贴纸、内凹、外发光）一点就套上；还能把预览区切成深底，看清阴影在深色界面上到底有没有用 —— 通常没有，得换描边。复制出来就是 `box-shadow` 与 `border-radius` 两行。
- **JSON 树**：接口返回一大坨时，真正想知道的往往是「这个字段在哪一层」。这一页把 JSON 折成树，默认只展开两层；搜索框输入键名，命中的行亮起来、上层自动展开、不相关的藏起来；点键名复制 `$.data.list[0].id` 这种路径（jq、Postman、代码里都能直接用），点「复制值」拿原始字符串。解析失败时给出第几行第几列，还能一键把光标跳到出错的位置。
