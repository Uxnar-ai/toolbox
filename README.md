## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-19）加到七十四个，新做六个：

- **标点转换**：中文标点 ↔ 英文标点、全角 ↔ 半角四个方向。先按占位符把网址、邮箱、小数（`3.14`）、时间（`9:30`）、千分位（`1,000`）、文件名、反引号代码抽出来保护，转换完再放回，所以「句号变点」这类规则改不坏正文里的链接。中文省略号是两个字符、英文引号要交替开合，都单独处理。
- **Nginx 反代配置**：填域名和本机端口，直接出能粘的 `server` 块 —— 80 跳 443、SSL 证书路径、反代头、WebSocket、超时、上传大小、gzip，勾一下还附带 `/_fonts/` 通道那一段。HTTP/2 新旧两种写法都给了。注释里写明该放宝塔的 extension 目录，主 conf 被面板重写也不会丢。
- **年龄计算**：周岁按日历推（先减日、不足借上月实际天数，再减月），不做「除以 365」那种近似；不满两岁自动切成「X 个月 Y 天」。顺带虚岁、生肖、星座、活了多少天/小时、下次生日倒计时、第 N 个整千天。还能把结果复制成一句话，填表直接用。
- **图片拼接**：三张图竖着接成一张长图、横着排做效果对比、或者拼九宫格，间距与背景色可调，导出 PNG / JPG。拖放、点选、`Ctrl+V` 三条入口，打开就带三张现画的示例图。
- **中文数字**：双向互转，粘什么都认。`1234567.89` → 一百二十三万四千五百六十七点八九；`三千零五` → 3005。按万、亿分段，段内零合并、末尾零不读，`10–19` 读「十」不读「一十」，反向还认「两」「壹贰叁」「〇」「点」「负」。

- **图片对比**：改版前后两张图放一起，拖动中线看左右两半、并排看，或者逐像素比出差异并标红，同时给出「不同像素数 / 占比」。尺寸不一致时 B 先缩放到 A 再比。

- **图片对比**：改版前后两张图放一起，拖动中线看左右两半、并排看，或者逐像素比出差异并标红，同时给出「不同像素数 / 占比」。尺寸不一致时 B 先缩放到 A 再比。

## 功能

- 标点转换：中文 ↔ 英文标点、全角 ↔ 半角四个方向，网址与 3.14 / 9:30 / 1,000 自动保护
- Nginx 反代配置：域名 + 端口出完整 server 块，含 80 跳 443、WebSocket、上传大小与 /_fonts/ 通道
- 年龄计算：精确到天的周岁、虚岁、生肖星座、活了多少天、下次生日倒计时，可复制成一句话
- 图片拼接：竖排长图 / 横排对比 / 九宫格，间距背景可调，拖放或粘贴导入，导出 PNG / JPG
- 中文数字：数字与读法双向互转，认「两」「壹贰叁」「点」「负」，混着写会直接报错
- 图片对比：拖动中线 / 并排 / 差异标红三种看法，标出不同像素的数量与占比
- 图片对比：拖动中线 / 并排 / 差异标红三种看法，标出不同像素的数量与占比
- 全部在浏览器里算：图片、文本、JSON 都不上传，页面里没有任何后端接口
