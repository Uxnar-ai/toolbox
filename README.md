## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-23）加到九十五个，新做四个：

- **截图打码**：拖张截图进来，在手机号、姓名、地址上按住拖个框，松开就糊好。马赛克按块打乱、高斯模糊柔一点、纯色块最保险；强度可调，能逐步撤销、也能一键还原原图，导出 PNG。图片全程留在浏览器里。
- **尺寸换算**：填一个数选个单位，px / rem / em / % / vw / vh / pt 一次全算出来，点一行就复制；参数区能改根字号、父字号和视口尺寸。另给设计稿 px → vw 的换算（375 / 750 / 1440 / 1920 预设）和一张 12 档字号阶梯，直接点着抄。
- **名单分组**：名单一行一个粘进来（逗号、顿号、分号、空格都认，重复的自动去掉），随机分成 N 组或每组 N 人，人数尽量平均；也能抽签，一次抽几个且不重复。随机数用的是系统加密随机数加拒绝采样，不是 `Math.random` 取模；结果一键复制成「第 1 组：…」。
- **容量与带宽**：标称 500 GB 的盘为什么只显示 465.7 GiB —— 十进制与二进制两列逐级对照，直接给结论；300 Mbps 换成 37.5 MB/s，附 100M 到 2G 的宽带对照表；再填文件大小和带宽，算出下载要多久（按 85% 有效速率）。

## 功能

- 截图打码：拖框就糊，马赛克 / 模糊 / 纯色三选一，可撤销可还原，导出 PNG
- 尺寸换算：px / rem / em / % / vw / vh / pt 一次算全，设计稿 px 转 vw 也有
- 名单分组：随机分组或抽签不重复，人数尽量平均，结果一键复制
- 容量与带宽：GB 与 GiB 对照、Mbps 转 MB/s、按带宽估下载耗时
- 全部在浏览器里算：图片、压缩包、文本、JSON 都不上传，页面里没有任何后端接口
