## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-20）加到七十九个，新做五个：

- **图片转 PDF**：拖几张照片或截图进来，↑↓ 调顺序，合成一个 PDF 下载。自己写了个最小 PDF 写入器：每张图先在 canvas 上重新编码成 JPEG，再按 DCTDecode 塞进页面对象，A4 / A5 / 跟图片一样大三种纸张、边距与画质可调。文件结构是手拼的，所以每页缩略图、页数、体积都当场给。
- **九宫格切图**：一张图平均切九张（也可 2×2 / 1×3 / 3×1），打包成一个 ZIP 下载，按文件名顺序发出去正好拼回原图。ZIP 用「只存储不压缩」的写法手拼，PNG 本身已经压过，套一层 deflate 反而慢。
- **JSON 转 Schema**：贴一段接口返回，推出每个字段的类型、必填项和数组里的结构，日期 / 邮箱 / 链接自动认格式。数组里多个元素会合并成一套结构，只在部分元素出现的字段不算必填；类型冲突的地方不硬猜，直接不限。
- **绩点换算**：填课程学分和成绩（百分制或优/良/中/及格都认），一次给出加权平均分和 4.0 / 4.3 / 5.0 三套绩点，每门课还标出自己在 4.0 制下的绩点。
- **单价比价**：同一样东西几个规格摆一起，折成每 100 克 / 每 100 毫升 / 每个，自动排序并标出最划算的那一个与其余贵多少。斤按 500 克、两按 50 克算，重量、容量、个数分开比，不混着来。

## 功能

- 图片转 PDF：多张图排序后合成一个文件，手写 PDF 结构，A4 / A5 / 原图三种纸张
- 九宫格切图：3×3 等六种切法，打包成 ZIP 一次下载，文件名即发布顺序
- JSON 转 Schema：推断类型、必填项、数组项合并，日期 / 邮箱 / 链接自动认格式
- 绩点换算：加权平均分 + 4.0 / 4.3 / 5.0 三套绩点，等级成绩也能折算
- 单价比价：折成每 100 克 / 100 毫升 / 每个，自动排序标出最划算
- 全部在浏览器里算：图片、文本、JSON 都不上传，页面里没有任何后端接口
