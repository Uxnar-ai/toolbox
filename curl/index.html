    单引号、双引号、反斜杠续行、`-d/--data/-H/-X/-u/-b/-F/--json` 都认；`-k -L -s -o` 这类只影响 curl 行为的参数不会写进代码。
    生成的代码只是骨架，跑之前把 Bearer 令牌、密码这类东西换成你自己的。
  


  

    所有解析和生成都在浏览器里做，命令里的令牌不会离开这台电脑。Go 用标准库 net/http，Python 用 requests（`pip install requests`）。
