    它只动空白，不动内容：标签、属性、字符串一个都不改，所以排完还能照常跑。JS 里的字符串、模板字符串、正则和注释也都原样保留。

    JS 不提供压缩：JS 压缩要处理自动补分号（换行在某些地方是语法），压错了页面直接白屏，这种事交给构建工具做更稳。
    HTML 压缩会去掉标签之间的空白，行内元素并排时可能贴在一起，介意就别压。
    CSS 压缩会删注释和多余空格，`calc(100% - 20px)` 里的空格会保留。
