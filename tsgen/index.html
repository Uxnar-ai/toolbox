JSON 转类型

把一段接口返回的 JSON 贴进来，直接给出 TypeScript 接口、Go struct 或 Python dataclass。

根类型名

接口返回的 JSON 改一个字就重算

TypeScript 数组里缺字段的会标成可选


    

  


  

  

  

    数字分不清整数和小数时按 number 处理；找不到值的字段（null）在 TypeScript 里写 null，在 Go / Python 里退成万能类型。
    只读这段 JSON，不上传。
  


  

    同一个数组里第二项多出来的字段，会被标成可选（TS 加 ?、Go 加 omitempty、Python 加 Optional）。
