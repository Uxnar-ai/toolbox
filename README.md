## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-14）加到五十一个，新做的是四个：算钱、转格式、算身、看时间。

- **个税与到手**：用工资薪金那套累计预扣法逐月算。输入税前月薪、五险一金（可按比例估也可填工资条上的真实数字）、专项附加扣除，出 12 个月的累计应税、累计个税、本月扣税和到手。年终奖同时算「单独计税」（除以 12 找月度税率）和「并入综合」，直接给出哪种更省、省多少。示例数字跑过手算核对：月薪 2 万、五险一金 22.2%、专项 2000 时全年个税 7752，月均到手 14914。
- **JSON 转表格**：对象数组、单个对象、JSON Lines 三种形状都认。嵌套对象拆成 `user.name` 这样的扁列，数组按逗号连成一格；导出 CSV 带 BOM（Excel 直接开不乱码）、TSV、Markdown 表格、SQL 插入四种，SQL 里数字不加引号、字符串按单引号转义。
- **体重与热量**：BMI 按中国成人标准分成偏瘦 / 正常 / 超重 / 肥胖四档，刻度条上有标记位置；基础代谢用 Mifflin-St Jeor，乘活动系数得每天总消耗，再给减脂 / 维持 / 增肌三档热量，并按蛋白质 1.6–1.8 g/kg、脂肪 25% 热量折出三大营养素克数。
- **番茄钟**：25 / 45 分钟专注、5 / 15 分钟休息，也能填任意分钟数当普通倒计时。圆环按剩余比例收缩，结束响三声并在本机记一个番茄（按本地日期存），标签页标题实时显示剩余时间；暂停/继续用时间戳算，切到别的标签页回来不会漂。


## 功能

- 个税与到手：累计预扣法逐月算，年终奖单独计税 vs 并入综合当场给结论，告诉你哪种省多少
- JSON 转表格：对象数组 / 单个对象 / JSON Lines 都认，嵌套拆成 user.name 列，出 CSV / TSV / Markdown / SQL
- 体重与热量：BMI 分级按中国标准，基础代谢乘活动系数给每天总消耗，再算减脂三档的热量与三大营养素
- 番茄钟：圆环倒计时、结束响一声并记一个番茄，标签页标题同步剩余时间，切走也不漂移
- 隐藏字符体检：零宽 / BOM / 不间断空格 / 全角空格 / 制表符逐字标出，一键清成干净文本
- 表格对齐：中英文按实际宽度补空格，自动判数字列靠右，Tab 数据直接转 Markdown 表格
- 阴影与圆角：滑块实时预览 box-shadow 与 border-radius，可切深底看效果，两行 CSS 复制走
- JSON 树：大 JSON 折叠浏览、搜键名自动展开上层、点键名复制 $.a.b[0] 路径
- curl 转代码：四种语言、认多行续行与合并短参数、JSON 内联成对象、表单转 URLSearchParams
- HTTP 状态码：54 条带中文解释与排查方向，含 nginx 与 Cloudflare 的非标准码
- .gitignore 生成：24 个栈按段拼接、跨块去重、反向规则保留，可复制可下载
- 贷款计算：等额本息与等额本金对比，月供 / 总利息 / 每期明细，末期消浮点尾差
- 五十一个工具同在一个静态站，零后端零端口
- 构建脚本从各工具模板生成，改动只在一处
- 文本对比：逐行对齐、行内字级高亮、相同段落折叠、差异可复制
- 二维码：中文 UTF-8、容错 L/M/Q/H、尺寸可调、下载 PNG、固定四个点静区
- 编码解码：Base64（网址安全字符）、网址、HTML、Unicode 转义、拆 JWT 并换算过期时间
- 哈希校验：MD5/SHA-1/SHA-256/SHA-512，粘贴校验值自动认算法比对
- 公共主题 12 个变量，日夜三态（跟随系统 / 浅 / 深），全站统一图标
- 窄屏单列，390px 下无横向溢出
- Cron 表达式：中文说明 + 下次 10 次、五段全语法、别名、报错精确到段
- 命名风格：八种写法一次出、缩写拆词、多行批量、整列可复制
- 日期计算：相差天数/工作日、年月日拆读、按天/工作日/月/年推进
- 随机生成：密码/UUID/十六进制/数字，安全随机源 + 强度估算
- CSV 转表格：自动认分隔符、引号内逗号、表头排序、六种导出格式
- 中英混排：中英/中数之间补空格、全角转半角、改动可标出
- 字数统计：中文字/英文词/段落/阅读时长 + 五个平台字数上限
- 网址拆解：参数改删实时重组、一键去跟踪参数、参数表转 JSON
- 首页即时搜索，二十个工具按关键词过滤
- 网段计算：网络地址/广播/可用范围/掩码互转、切子网、判定 IP 是否在段内
- 百分比计算：打折、涨跌幅、占比、增减四块，填两个数直接出结果
- 乱码修复：UTF-8/GBK/Big5 互解的几种可能一起列出并排第一，网址与转义也能还原
- Markdown 预览：标题/列表/表格/代码块实时渲染，可复制 HTML 或下载成网页
- 二维码识别：截图/照片/粘贴截图读出文字与链接，多张一起读，纯本地解码
- 文本脱敏：六类敏感信息逐类开关、保留首尾或整段打码、结果高亮可复制
- 正则查找替换：实时预览、分组引用、五个常用预设、只看匹配
- YAML / JSON 互转：报错定位到行列、缩进可选、可往返验证与下载
- 首页「最近用过」：点过的工具置顶成胶囊，存在本地不上传
- WebP 四档质量比体积：一屏看清 60/75/85/95 各占多大，点一下套用
