## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-26）加到一百零七个，新增分期真实利率、Docker 命令速查、systemd 服务生成、装修用量计算：

- **分期真实利率**：填本金、期数、月费率，直接给两个数 —— 嘴上说的「费率 × 12」和按现金流折现算出来的真实年化。手续费按最初借款额收、本金却逐月在还，所以月费率 0.6% 的 12 期实际是 13.84%，页面把 1.92 倍的差距摆出来，还带每期还款明细和常见费率对照表。
- **Docker 命令速查**：45 条命令按「日常 / 日志 / 镜像 / 清理 / Compose / 网络与卷」分组，每条一个场景名加一句说明；搜「日志」「清理」「端口」即时过滤，点一下复制。
- **systemd 服务生成**：填启动命令、工作目录、运行用户和环境变量，生成能直接用的 .service；勾上定时同时给一份 .timer。附带整段部署命令（tee 写文件 → daemon-reload → enable --now）和日常操作清单。
- **装修用量计算**：量个长宽高，算出墙面、顶面、地面，再按每升涂布率和遍数给桶数；地板按规格与损耗率给块数，踢脚线扣掉门洞，连大概花费一起列。


## 功能

- 分期真实利率：月费率换算真实年化（0.6% × 12 期 = 13.84%），含放款手续费、每期还款明细
- Docker 命令速查：45 条按场景分组，搜「日志 / 清理 / 端口」即时过滤，点一下复制
- systemd 服务生成：.service 与 .timer 一起给，附 deploy 三条命令和日常操作清单
- 装修用量计算：涂料桶数、地板块数（含损耗）、踢脚线米数与大概花费
- 一百零七个工具同在一个静态站，主题跟随系统、深浅两态、窄屏可用
- 全部在浏览器里算：图片、压缩包、文本、JSON 都不上传，页面里没有任何后端接口
