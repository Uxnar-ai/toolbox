## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-24）到一百个，新做五个：

- **跑步配速**：填距离和用时（5 公里 / 10 公里 / 半马 / 全马一键切），立刻给出配速、时速、每 400 米和每英里用时，再按每公里列出分段；同一页用 Riegel 公式估算别的距离大概跑多久 —— 距离拉长一倍不是时间翻倍，而是约 2.06 倍。
- **复利与定投**：本金 + 每月定投 + 年化 + 年数，算出到期余额、累计投入、赚了多少和翻几倍，再按通胀折成「实际能买多少东西」；下面逐年列出本金与余额，一眼看出后几年收益超过投入。
- **动画缓动曲线**：拖曲线上的两个控制点调手感，右边直接给出 `cubic-bezier(...)`，点一下复制；七种预设（慢起、急刹、两头缓等）配一个能真跑的小球，调完当场看。
- **WiFi 二维码**：填 SSID、密码、加密方式（WPA / WEP / 无密码），生成扫码直连的二维码，可下载 720 / 1000 / 1600 像素 PNG；页面底下那行会写出码里实际的字符串，扫不出来时能对着排查。
- **截图美化**：截图拖进来，套渐变或纯色背景、加留白圆角和投影，可选 1:1 / 4:3 / 16:9 画布，导出 1200–2400 像素 PNG。做封面、写教程、发对比图用。

## 功能

- 跑步配速：配速 / 时速 / 分段表，外加 5K、半马、全马的完赛推算
- 复利与定投：到期余额、赚了多少、通胀后还值多少，逐年明细
- 动画缓动曲线：拖动调 cubic-bezier，七种预设，当场跑一遍
- WiFi 二维码：扫码直连，可下载 PNG，码里写的字符串明着列出来
- 截图美化：渐变背景 + 圆角投影，1:1 / 4:3 / 16:9，导出高清 PNG
- 全部在浏览器里算：图片、压缩包、文本、JSON 都不上传，页面里没有任何后端接口

## 技术栈
