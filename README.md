# 工具台 toolbox · 十二个打开就能用的小工具

> 十二个打开就能用的小工具合在一个静态站里：JSON 排版、文本整理、时间戳、正则解剖台、文本对比、编码解码、哈希校验、金额大写、单位换算、颜色工具箱、二维码、图片压缩。零后端、零端口。

[English](README.en.md) | 中文

## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮把工具箱从八个补到十二个，加的都是「手边真会用」的：

- **文本对比**：改前改后各粘一遍。先用最长公共子序列对齐整行，再把成对的删/加行做字级比对，只把真正变了的字标出来；长段相同的行折叠成一行提示，差异可以按 `+`/`-` 的形式复制走。
- **二维码生成**：自带编码库（MIT），中文按 UTF-8 进码而不是让浏览器按 Latin-1 编，容错 L/M/Q/H 四档，静区固定四个点，下载的 PNG 按整数倍放大，扫得动。
- **编码解码**：Base64（含网址安全字符 -_）、网址转义、HTML 转义、Unicode 转义、拆 JWT —— JWT 会顺手把签发/过期时间换算成本地时间并算出还剩多久，但不验签，页面上写清楚。
- **哈希校验**：文件拖进来出 MD5 / SHA-1 / SHA-256 / SHA-512。SHA 系列走浏览器自带的 crypto.subtle，MD5 浏览器没有，页面里自己实现（已用空串、abc、1000 个 a、中文串四组向量对过）。把官网给的校验值粘进比对框，按长度自动认出是哪种算法并判定对不对。

顺带修了两个一直存在的小毛病：构建时 favicon 的模板引用从来没被替换过（每个工具页的标签图标都是 404），以及首页按分组渲染时，新加的工具会因为追加在表尾而重新起一个同名分组头。现在按 `GROUP_ORDER` 排序渲染，图标也统一从 `assets/icon.svg` 取。

## 功能

- 十二个工具同在一个静态站，零后端零端口
- 构建脚本从各工具模板生成，改动只在一处
- 文本对比：逐行对齐、行内字级高亮、相同段落折叠、差异可复制
- 二维码：中文 UTF-8、容错 L/M/Q/H、尺寸可调、下载 PNG、固定四个点静区
- 编码解码：Base64（网址安全字符）、网址、HTML、Unicode 转义、拆 JWT 并换算过期时间
- 哈希校验：MD5/SHA-1/SHA-256/SHA-512，粘贴校验值自动认算法比对
- 公共主题 12 个变量，日夜三态（跟随系统 / 浅 / 深），全站统一图标
- 窄屏单列，390px 下无横向溢出

## 技术栈

HTML · CSS · 原生 JS（构建脚本 Python 3）

## 运行

```bash
python scripts/build_toolbox.py
# 然后把 src/toolbox/ 丢给任意静态服务器
```
