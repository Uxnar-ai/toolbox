## 这是什么

每个工具都是纯前端计算，页面里不出现服务器。构建脚本 `scripts/build_toolbox.py` 从各工具的模板读页面，改写静态资源路径、注入统一的返回胶囊，再拼一张按用途分组的首屏；公共的 theme.css / base.js 只留一份。产物是纯静态目录，任何静态服务器都能直接发。

这一轮（2026-11-25）加到一百零一个，新增「城市天气」，首页多一个「生活查询」分组：

- **城市天气**：输城市名或 9 位城市代码，出当前温度、体感、湿度、风力风向、气压、日出日落和 PM2.5 / PM10；下面七天预报每天一行，带温度区间条，下雨概率 ≥20% 才标出来。
- **城市代码内嵌**：2500 多个城市的「城市名 ↔ 中国天气网 9 位代码」表整个打包进页面，输入即联想（按名字或代码前缀都行），断网也能查表。
- **记住查过的城市**：查过的城市存在浏览器本地（最多 8 个），一排胶囊一点就开，点 × 删掉；下次打开默认回到上次看的城市，坐标也缓存着，同一个城市不重复解析。
- **没有中转**：天气和空气质量都从浏览器直连 Open-Meteo 的公开接口，页面里不经过任何自己的服务器。


## 功能

- 城市天气：温度、体感、湿度、风力风向、气压、日出日落 + 七天预报
- 城市名或 9 位城市代码都认，2500 多条码表内嵌，输入即联想
- 查过的城市留在本机（最多 8 个），一点就开，下次默认回到上次那个
- PM2.5 / PM10 按同一口径分档，七天预报带温度区间条
- 天气数据浏览器直连公开接口，没有中转服务器
- 全部在浏览器里算：图片、压缩包、文本、JSON 都不上传，页面里没有任何后端接口
